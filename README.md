# Smart Museum Artifact Conservation System

## Background
A museum utilizes a specialized chamber to protect extremely valuable historical artifacts. The chamber contains sensors and an automated environmental-control system that continuously monitors:
- Temperature
- Humidity
- Light exposure
- Vibration
- Chamber door status
- Artifact condition
- Power availability

**Objective:** The system must maintain specific environmental conditions for the artifact and react appropriately when abnormal conditions occur.

## Project Scope: Software Verification and Validation
This repository maps the traditional Software V&V concepts into a modern workflow. 
- **Validation** is tracked via GitHub Issues and Projects, mapping operation schemas to acceptance criteria.
- **Verification** will be managed via branch protection rules and automated checks.
